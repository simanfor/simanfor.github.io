    Platform execution pathways

    SIMANFOR is designed to accommodate diverse technical profiles, from students and forest practitioners seeking to assess a single silvicultural prescription, to researchers processing thousands of inventory plots in high-performance computing environments.

    To address these varying needs, three interaction pathways with the platform exist. This guide outlines each alternative, clarifies the current operational status of each service, and provides a decision matrix to help you select the most suitable pathway.

    Web platform: the primary and recommended pathway

    The web platform available at simanfor.es is the official, primary, and recommended pathway for the vast majority of users (forest managers, environmental consultants, educators, and students).

    Key features

    • Cloud service with zero installation: Runs directly in any modern web browser (Firefox, Chrome, Edge, Safari). Requires no local software installation, programming environment configuration, or operating system dependency management.
    • Open and free access: Available freely without licensing fees. Only requires registering a user account to privately store inventories, scenarios, and outputs.
    • Guided visual interface: Allows users to upload inventory files in Excel using standardized templates, select models from the official catalog, define thinning interventions step by step, and inspect diagnostic reports.
    • Direct export: Simulation results are compiled into downloadable Excel workbooks organized by stand-level trajectories, residual inventory tables, and commercial timber assessments.

    Recommended starting pathway

    If you are taking your first steps with SIMANFOR, completing an academic assignment, or drafting a forest management plan for a specific stand or property, the web platform covers 100% of your computational requirements without technical friction.

    Docker container

    Historically, SIMANFOR provided public Docker container images to enable local offline execution on standalone machines.

    Current operational status

    Public Docker container images for external users are temporarily suspended due to technical review and infrastructure maintenance.

    • Technical rationale: The simulator core and model architecture have undergone significant refactoring toward a Single Source of Truth (SSOT) architecture and numerical performance optimizations. Earlier container images are being redesigned to ensure exact synchronization with the latest verified versions of all biometric models.
    • Current recommendation: While this update is completed, all users needing to run simulations should use the cloud-based web platform (simanfor.es), which features the latest verified versions of the entire model catalog.
    • Future availability: Once the verification of the lightweight updated images is complete, a comprehensive local deployment guide will be published in this section.

    Docker service under update

    The Docker section of the user documentation remains under maintenance. The cloud platform at simanfor.es is fully operational and serves as the direct, verified alternative.

    Python simulator and new model development

    For research groups, forest modelers, and advanced data scientists requiring capabilities beyond the graphical interface, the SIMANFOR computational engine is implemented as a modular tool in Python.

    Specialized use cases

    • Large-scale batch simulations: Systematic processing of thousands of Spanish National Forest Inventory (NFI) plots or extensive regional biometric databases.
    • High-performance computing (HPC): Distributed simulation deployments on high-performance servers.
    • Integration into analytical pipelines: Programmatic connection of the simulator with R or Python workflows for statistical modeling, multi-objective optimization, or advanced visualization.
    • Model calibration and integration: Implementation of new growth functions, allometric relationships, or parameters for species and regions not yet covered in the catalog.

    Access protocol and scientific collaboration

    Because these environments require close coordination with the SIMANFOR development team, access to the advanced simulator scripts and model integration is managed through scientific or technical collaboration agreements.

    If your institution, research project, or case study requires this deployment mode, please contact the team directly at simanfor.forest@uva.es, including: 1. The research scope and project objectives. 2. The estimated volume of inventories and scenarios to be processed. 3. The biometric equations or models you wish to calibrate or test within the simulator.

    The following table summarizes the optimal interaction pathway according to your role and goals:

    User profile Primary goal / requirement Technical prerequisites Recommended pathway
    University student Coursework in Silviculture, Forest Management, or Biometrics. Web browser and free account. Web platform (simanfor.es)
    Forestry educator Classroom workshops and Bachelor's/Master's thesis supervision. Web browser and internet connection. Web platform (simanfor.es)
    Field manager / Practitioner Comparing silvicultural regimes for management plans. Stand or plot inventory data in Excel. Web platform (simanfor.es)
    Environmental consultant Quantifying carbon stocks, biomass, and timber yields for clients. Standard inventory templates. Web platform (simanfor.es)
    Researcher / Data scientist Regional/national-scale analysis with NFI plots or HPC clusters. Python/R proficiency and Linux/Slurm environment. Python upon request (simanfor.forest@uva.es)
    Forest modeler Integrating new biometric equations into the SIMANFOR catalog. Empirical calibration and team collaboration. Scientific collaboration (simanfor.forest@uva.es)
