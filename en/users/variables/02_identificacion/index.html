    Inventory identification and characteristics

    Variables designed to uniquely identify inventories, sample plots, and individual trees within the simulator, as well as qualitative parameters of form, quality, and health status.

    Plot-level variables

    • ID_inventory (INVENTORY_ID) — text  •  dimensionless  •  output: INVENTORY_ID

      Unique identifier of the forest inventory.

      Accepted inventory aliases: id_inventario, inventory, id_inventory, inventario

    • ID_plot (PLOT_ID) — text  •  dimensionless  •  output: PLOT_ID

      Unique plot identifier.

      Accepted inventory aliases: id_parcela, plot, parcela, id_plot, id_parc

    • Country — text  •  dimensionless  •  output: COUNTRY

      Country where the plot is located.

    • Province — text  •  dimensionless  •  output: PROVINCE

      Administrative province where the plot is located.

    • Municipality — text  •  dimensionless  •  output: MUNICIPALITY

      Municipality where the plot is located.

    • Biogeographic_region — text  •  dimensionless  •  output: BIOGEOGRAPHIC_REGION

      Biogeographic region of the stand (e.g. Mediterranean, Atlantic).

    • Forest — text  •  dimensionless  •  output: FOREST

      Name of the forest estate.

    • Study_area — text  •  dimensionless  •  output: STUDY_AREA

      Identifier or designation of the study area.

    • Stand_origin — text  •  dimensionless  •  output: STAND_ORIGIN

      Origin of the forest stand (natural or plantation/artificial).

    • Natural_regeneration (REGENERATION) — integer  •  dimensionless  •  output: REGENERATION

      Presence or density class of natural regeneration in the plot. Used in the Romania stand model and takes values from 1 to 8.

    • ID_species_{num} (ID) — integer  •  dimensionless  •  output: ID_species_{num}  •  multi-species: sp1, sp2, sp3

      Identifier code of species {num} according to the Spanish National Forest Inventory (SNFI) standard.

      Accepted inventory aliases: {sp}_id, id_{sp}, species_{num}_id, especie_{num}_id, id_sp{num}

      Simulation breakdown: This variable is automatically expanded for each target stand species (ID_species_SP1, ID_species_SP2, ID_species_SP3).

    • Name_species_{num} (NAME) — text  •  dimensionless  •  output: Name_species_{num}  •  multi-species: sp1, sp2, sp3

      Formatted scientific name of species {num} present in the plot.

      Accepted inventory aliases: {sp}_name, name_{sp}, species_{num}_name, especie_{num}_nombre, nombre_{sp}

      Simulation breakdown: This variable is automatically expanded for each target stand species (Name_species_SP1, Name_species_SP2, Name_species_SP3).

    • Clone_species_{num} (CLONE) — text  •  dimensionless  •  output: Clone_species_{num}  •  multi-species: sp1, sp2, sp3

      Clone identifier for species {num}. Currently used in Populus_sp_stand__NE model with fields like I214, MC or LA.

      Simulation breakdown: This variable is automatically expanded for each target stand species (Clone_species_SP1, Clone_species_SP2, Clone_species_SP3).

    • Species_composition — text  •  dimensionless  •  output: SP_COMP

      Description of species mixture or proportions in the plot.

    • Year — integer  •  dimensionless  •  output: YEAR

      Year associated with the rest of the state variables.

      Accepted inventory aliases: ano, Año, anio, year

    Tree-level variables

    • id_inventory (inventory_id) — text  •  dimensionless  •  output: inventory_id

      Identifier of the inventory the tree belongs to.

      Accepted inventory aliases: id_inventario, inventory, id_inventory, inventario

    • id_plot (plot_id) — text  •  dimensionless  •  output: plot_id

      Identifier of the plot the tree belongs to.

      Accepted inventory aliases: id_parcela, plot, parcela, id_plot, id_parc

    • id_tree (tree_id) — text  •  dimensionless  •  output: tree_id

      Unique tree identifier within the plot.

      Accepted inventory aliases: id_arbol, tree, id_tree, arbol

    • species_id — integer  •  dimensionless  •  output: species_id

      Numeric or identifier code of the tree species according to the Spanish National Forest Inventory (SNFI) or equivalent.

      Accepted inventory aliases: species, id_especie, especie, sp, cod_esp

    • species_name — text  •  dimensionless  •  output: species_name

      Scientific or canonical name of the tree species.

      Accepted inventory aliases: nombre, especie_nombre, species_name

    • status — text  •  dimensionless  •  output: status

      Defines the condition of the tree during the simulation step (alive = alive tree that remains in the simulation for the next time step; new = new tree assigned a new code, originated by natural ingrowth; dead = tree that died naturally during the projection; ingrowth = tree that entered the simulation during projection due to natural ingrowth; harvested = fully harvested tree (entire expansion factor extracted); partially harvested = partially harvested tree (only part of the expansion factor extracted).

    • timber_quality (quality) — text  •  dimensionless  •  output: quality

      Timber technological quality class of the tree.

    • stem_shape (shape) — text  •  dimensionless  •  output: shape

      Stem straightness or tree shape code.

    • social_class — integer  •  dimensionless  •  output: social_class

      Sociological canopy position of the tree according to Kraft classification.

    • special_param — decimal  •  dimensionless  •  output: special_param

      Spanish National Forest Inventory (SNFI) special parameters code. In growth models (Aguirre et al., 2026), it modifies annual diameter and height increment for species with special uses or conditions (such as resin tapping in Pinus pinaster or cork debarking in Quercus suber; default 1 = not resinated/not debarked, 0 = no special parameter).

    • bearing — decimal  •  deg  •  output: bearing

      Azimuthal bearing measured from the plot center to the tree.

    • distance — decimal  •  m  •  output: distance

      Horizontal distance from the plot center to the tree.

    • remarks — text  •  dimensionless  •  output: remarks

      Field notes or silvicultural remarks about the individual tree.
