    General variables catalog

    This section contains the comprehensive and unified dictionary of all variables used across the SIMANFOR platform. These variables cover both initial inventory metrics and those calculated by forest models and generated in output files.

    Quick variable search

    To instantly locate any variable by its descriptive name, output symbol or abbreviation, or accepted inventory synonym, use the search bar located in the upper-right corner of the screen (or press s or f).

    Information levels

    In SIMANFOR, variables are structured primarily into two hierarchical levels:

    • Plot-level variables: Describe overall stand, plot, or inventory characteristics per unit area (frequently scaled per hectare, such as density in trees/ha or basal area in m²/ha).
    • Tree-level variables: Record measurements and estimates of individual inventoried trees (diameter at breast height, total height, unit volume, biomass fractions).

    Conventions and standards

    • Standardized units: All units are explicitly stated in lowercase (e.g., t/ha for stand biomass and carbon, kg for individual tree biomass and carbon, m3/ha and dm3 for volumes, cm for diameters, m for heights, - for dimensionless indices, and ratio for proportions between 0 and 1).
    • Output labels and symbols: The bold name is the official descriptive name and the column header produced in simulator output files. For variables with a standard mensurational symbol or abbreviation (such as N for density or G for basal area), it is shown in parentheses beside the name: Density (N), which corresponds to the header in output files.
    • Accepted names in inventory: The simulator flexibly and case-insensitively accepts common synonyms (aliases) when importing inventories from Excel, CSV, or JSON formats, automatically including the Spanish denomination.
    • Multi-species variables: To perform stand calculations by species, some variables are presented broken down by species by adding the numerical suffix of the corresponding species (Species_SP1_name, Species_SP2_name, Species_SP3_name).
    • Dynamic management variables: Silvicultural interventions and demographic events incorporate standardized prefixes: _corta / _harvest (removals from thinning or felling), _muerto / _dead (natural mortality), and _incorporado / _ingrowth (ingrowth, considering trees of inventoriable size with diameter at breast height >= 7.5 cm and not seedlings from natural regeneration).

    Interpretation of variable entries

    Each catalog entry systematically describes variable attributes to simplify identification both during field inventory preparation and when analyzing simulation output files.

    Structure of each entry

    • Name and output symbol: Official descriptive name in bold. If a standard technical symbol or abbreviation exists, it appears in parentheses: Name (Symbol). This symbol (or the name itself if no specific abbreviation exists) is the exact column header produced in simulator output files (Excel or CSV).
    • Data type: Technical value format (text, decimal, integer).
    • Units: Standardized measurement unit (dimensionless, cm, m, m2/ha, trees/ha, t/ha, ratio).
    • Multi-species tag: For variables broken down by species, indicates available numerical suffixes (multi-species: sp1, sp2, sp3).
    • Description: Technical or mensurational definition of the parameter.
    • Accepted names in inventory: Synonyms and column headers flexibly and case-insensitively accepted when importing inventories in Excel, CSV, or JSON (including the Spanish denomination).
    • Simulation breakdown: In multi-species variables, explanatory callout listing the specific disaggregated columns produced in outputs.
    • References: In modeled or empirical variables, scientific citations with direct DOI links to publications containing implemented equations.

    Example cases

    1. Inventory and basic setup variable

    Variables intended to uniquely identify plots or trees in input inventory files:

    • ID_inventory — text  •  dimensionless

      Unique identifier of the forest inventory.

      Accepted names in inventory: id_inventario, inventory, id_inventory, inventario, ID_inventario

    Interpretation: Since it lacks an abbreviated symbol in parentheses, the output column header will be ID_inventory (or Inventory_ID). In field inventory files uploaded to SIMANFOR, any of the listed names is recognized.

    2. Mensurational variable with standard symbol and multi-species breakdown

    Stand metrics calculated both globally and broken down for each target species:

    • Density (N) — decimal  •  trees/ha  •  multi-species: sp1, sp2, sp3

      Number of trees per hectare.

      Accepted names in inventory: n, pies_ha, densidad, density, Densidad

      Simulation breakdown: This variable is automatically expanded for each target stand species (Density_SP1, Density_SP2, Density_SP3).

    Interpretation: In downloaded simulation results, overall stand density is reported under column N, while species-specific densities appear under columns N_sp1, N_sp2, and N_sp3.

    3. Estimated variable with scientific references

    Variables calculated using biological, allometric, or empirical models implemented in the simulator:

    • N_cones (N_cones) — decimal  •  cones/ha/year

      Mean annual pine cone production per hectare.

      References:

      • Calama & Montero (2006). Cone and seed production from stone pine (Pinus pinea L.) stands in Central Range (Spain). European Journal of Forest Research. (DOI:10.1007/s10342-005-0100-8)
      • Calama et al. (2008). An empirical ecological-type model for predicting stone pine (Pinus pinea L.) cone production in the Northern Plateau (Spain). Forest Ecology and Management. (DOI:10.1016/j.foreco.2007.09.079)

    Interpretation: The output column will be named N_cones. The entry links directly to reference scientific papers containing implemented equations.

    4. Dynamic management and demographic variables

    Variables quantifying changes between simulation cycles resulting from thinnings, natural mortality, or ingrowth:

    • Volume_harvest (V_harvest) — decimal  •  m3/ha

      Merchantable timber volume removed during thinning or felling operations in the period.

    Interpretation: Silvicultural event variables incorporate standardized prefixes or suffixes: _corta / _harvest or _cut (removals), _muerto / _dead (natural mortality), and _incorporado / _ingrowth (new recruit trees).

    Climatic variables and bioclimatic indices Meteorological precipitation, seasonal temperature parameters, and climatic indices (such as Martonne index) required by climate-sensitive growth models. 22 View variables
