    Obtención de la imagen y primer contacto

    El simulador oficial de SIMANFOR está disponible públicamente como una imagen en el registro de contenedores de GitHub (GitHub Container Registry). Puedes descargarlo y realizar una prueba rápida de ejecución para comprobar que tu entorno de Docker está listo para trabajar.

    Descargar la imagen del simulador

    La imagen estándar y recomendada para la mayoría de usuarios es la que contiene la etiqueta de versión más reciente (latest). Para descargarla en tu equipo, abre la terminal y ejecuta este comando:

    docker pull ghcr.io/simanfor-dask/simulator:latest

    Una vez que termine el proceso de descarga, puedes verificar que la imagen se ha guardado correctamente en tu disco local listando las imágenes disponibles:

    docker image ls

    En la lista resultante deberías ver una línea correspondiente a ghcr.io/simanfor-dask/simulator con el tag latest.

    Versiones y variantes disponibles

    Aunque la etiqueta :latest apunta siempre a la última versión estable compilada, existen otras opciones disponibles en el registro. Si necesitas utilizar una versión histórica concreta o una rama de desarrollo específica (por ejemplo, para reproducir un estudio científico con la versión exacta con la que se programó), puedes sustituir el tag final del comando.

    Puedes revisar la lista completa de versiones, etiquetas e imágenes en el enlace público de los paquetes de SIMANFOR-Dask en GitHub.

    Para descargar una versión específica (por ejemplo, la v1.0.2), el comando sería:

    docker pull ghcr.io/simanfor-dask/simulator:v1.0.2

    Comprobación de funcionamiento inicial

    Para verificar que el contenedor funciona en tu máquina sin errores, puedes lanzar el simulador de manera directa sin pasarle ningún archivo ni parámetro:

    docker run ghcr.io/simanfor-dask/simulator:latest

    Al ejecutar este comando, el simulador iniciará un escenario de prueba preconfigurado de forma interna dentro del contenedor. En la consola verás los mensajes habituales del proceso de simulación forestal de SIMANFOR.

    Limitación de la prueba inicial

    Este comando ejecuta una simulación interna que sirve únicamente para verificar que el contenedor arranca bien en tu ordenador. Dado que los contenedores son entornos efímeros y aislados, cualquier archivo de resultados que genere esta simulación de prueba se eliminará automáticamente en cuanto termine el proceso.

    Para procesar tus propias plantillas de inventario y guardar los resultados en tu disco duro, debes configurar carpetas compartidas. Tienes todos los pasos detallados en la guía de volúmenes y carpetas de trabajo.
