    Introducción a la simulación con Docker

    El simulador de SIMANFOR sirve para evaluar alternativas de gestión forestal y estimar el crecimiento de los árboles con el paso de los años. Antes de contar con esta opción, ejecutarlo en un ordenador local obligaba a configurar entornos de programación, instalar librerías específicas y pelearse con dependencias de software que cambiaban según cada máquina.

    Para ahorrar estos pasos a investigadores, técnicos de campo y estudiantes, distribuimos el simulador metido en un contenedor de Docker. Esta tecnología permite que las simulaciones se ejecuten en un entorno aislado. De esta manera, el programa funciona exactamente de la misma forma en Windows, macOS o Linux sin interferir con la configuración del equipo que utilices para trabajar.

    ESTO ES UN CAMBIO

    Conceptos clave de la tecnología

    Si no has utilizado Docker nunca, la forma más rápida de entenderlo es comparándolo con los contenedores marítimos:

    • La imagen funciona como la plantilla o el molde. Es un paquete cerrado que contiene el simulador y todas las dependencias internas que le hacen falta para correr. Es estática, por lo que no se puede cambiar.
    • El contenedor representa la ejecución en sí. Es el simulador en funcionamiento creado a partir de la imagen. Puedes levantar, apagar y destruir tantos contenedores como quieras sin alterar la plantilla original.
    • Los volúmenes sirven como carpetas compartidas. Dado que los contenedores son aislados y borran su contenido al detenerse, necesitas una vía para pasar datos. El volumen vincula una carpeta de tu disco duro con el contenedor. Así, el simulador lee tus plantillas de inventario forestal y te devuelve los Excel de salida en tu propia máquina.

    Instalación y requisitos previos

    Para poder ejecutar la versión Docker del simulador, debes instalar la aplicación adecuada para tu sistema operativo:

    1. Instalación del software:
      • Windows y macOS: Descarga e instala Docker Desktop desde la página oficial.
      • Linux: Instala Docker Engine usando el gestor de paquetes propio de tu distribución.
    2. Prueba de funcionamiento: Abre una consola de comandos y comprueba que Docker responde bien con este comando: 
      docker --version

    Guía rápida de comandos

    Esta tabla recoge los comandos de Docker que más vas a utilizar al trabajar con el simulador de SIMANFOR:

    Comando Qué hace Cuándo se usa
    docker pull <imagen> Descarga una imagen de contenedor desde un servidor. Para descargar el simulador por primera vez o actualizarlo.
    docker run <opciones> <imagen> Arranca un contenedor nuevo basado en la imagen indicada. Para lanzar un proceso de simulación forestal.
    docker ps Muestra los contenedores que están funcionando ahora mismo. Para comprobar si una simulación larga sigue activa.
    docker ps -a Lista todos los contenedores, tanto activos como ya parados. Para inspeccionar ejecuciones anteriores que ya terminaron.
    docker logs <contenedor> Enseña las salidas de consola y avisos del contenedor. Para ver los mensajes de error del simulador si algo falla.
    docker rm <contenedor> Borra de la memoria local un contenedor que ya está parado. Para limpiar y recuperar espacio en el disco duro.
    docker image ls Muestra las imágenes que tienes guardadas en local. Para comprobar qué versión del simulador tienes descargada.
    docker rmi <imagen> Elimina una imagen de la máquina local. Para descartar versiones antiguas del simulador que ya no uses.
